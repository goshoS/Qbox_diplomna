# 💬 Qbox - Платформа за въпроси и отговори (Q&A)

![Python](https://img.shields.io/badge/Python-3.10+-blue?style=for-the-badge&logo=python)
![Django](https://img.shields.io/badge/Django-6.0.4-092E20?style=for-the-badge&logo=django)
![PostgreSQL](https://img.shields.io/badge/PostgreSQL-316192?style=for-the-badge&logo=postgresql)
![Bootstrap](https://img.shields.io/badge/Bootstrap-5.3-7952B3?style=for-the-badge&logo=bootstrap)

**Qbox** е съвременна, уеб-базирана информационна система за споделяне на знания, базирана на модела "Въпроси и Отговори" (подобно на StackOverflow/Quora). Платформата предоставя интерактивна и сигурна среда, в която потребителите могат да задават въпроси, да публикуват отговори, да оценяват съдържание и да го категоризират.

Проектът е разработен с фокус върху **сигурността, производителността и отличното потребителско изживяване (UX)**, включвайки асинхронна обработка на данни (AJAX), адаптивен дизайн и специализиран административен контролен панел.

##  Основни функционалности

* **Потребителски профили:** Регистрация с динамична AJAX валидация в реално време, визуален индикатор за сила на паролата и управление на профила.
* **Q&A Интеракция:** Задаване на въпроси и отговори с автоматично филтриране на нецензурен език (БГ и EN).
* **Асинхронни операции (AJAX):** Гласуване (Like/Dislike) и търсене в реално време без презареждане на страницата (Partial Rendering).
* **Динамични тагове:** Интеграция с `Tagify` за визуално управление, автодовършване и ограничаване на тагове.
* **Система за модерация:** Възможност за докладване (Report) на проблемно съдържание.
* **Административен панел:** Специализиран (custom) интерфейс за управление на потребители, въпроси, тагове и доклади, базиран на ролеви модел (Admin / SuperAdmin).
* **Персонализация:** Вградена поддръжка на Светла и Тъмна тема (Dark/Light mode) с адаптивни UI компоненти.
* **Mobile-First Design:** Напълно оптимизиран за мобилни устройства с Offcanvas меню и touch-friendly елементи.

##  Сигурност и защита

Системата е проектирана с внедрени най-добри практики за киберсигурност:

1. **Защита на данните (Environment Variables):** Всички чувствителни данни (като тайни ключове и пароли за базата данни) са изнесени извън сорс кода чрез `python-decouple` и се зареждат от `.env` файл.
2. **Защита от уеб атаки:** 
   - Вградена CSRF (Cross-Site Request Forgery) защита на всички форми и AJAX POST заявки.
   - Защита срещу XSS (Cross-Site Scripting) чрез автоматично ескейпване на темплейтите в Django.
   - Защита от SQL Injection чрез използването на Django ORM.
3. **Сървърна валидация (Server-side Validation):** Никога не се разчита само на JavaScript. Всички входни данни (дължина на пароли, нецензурни думи, уникалност на имейл) се валидират стриктно на сървъра (Custom Validators).
4. **Контрол на достъпа (RBAC):** Строга йерархия на ролите (Гост, Потребител, Админ, Суперадмин) с помощта на Custom Decorators (`@admin_required`, `@superuser_required`). Суперадминистраторите са защитени от изтриване през интерфейса.
5. **Предотвратяване на Double Submit:** Имплементирана е JavaScript логика, която блокира бутоните за публикуване след първото натискане, предотвратявайки спам или дублиране на записи при бавна мрежа.

##  Инструкции за стартиране (Setup Guide)

Следвайте тези стъпки, за да стартирате проекта на вашата локална машина.

### 1. Предварителни изисквания
* [Python 3.10 или по-нова версия](https://www.python.org/downloads/)
*[PostgreSQL](https://www.postgresql.org/download/) инсталиран и работещ.
* Git

### 2. Клониране на хранилището
```bash
git clone <URL_НА_ВАШЕТО_ХРАНИЛИЩЕ>
cd Qbox_2
```

### 3. Създаване на виртуална среда

```bash
# Създаване на средата
python -m venv .venv

# Активиране (за Windows)
.venv\Scripts\activate

# Активиране (за macOS/Linux)
source .venv/bin/activate
```

### 4. Инсталиране на зависимостите

```bash
pip install -r requirements.txt
```

### 5. Конфигурация и външни ключове (.env)

Системата изисква конфигурационен файл, за да работи. В основата на проекта (където се намира `manage.py`) създайте файл с име `.env`.

Въведете следните променливи вътре:

```env
# Тайният ключ на Django (Генерирайте сигурен ключ: https://djecrety.ir/)
SECRET_KEY=въведете_вашият_генериран_таен_ключ_тук

# Режим на дебъгване (Сложете False за продукционна среда)
DEBUG=True

# Конфигурация на PostgreSQL базата данни
DB_NAME=qbox2_db
DB_USER=postgres
DB_PASSWORD=вашата_парола_за_postgres
DB_HOST=localhost
DB_PORT=5432
```

*Забележка: Qbox към момента не изисква платени API ключове от трети страни (като Google OAuth или Stripe). Всички външни ресурси се управляват локално или през безплатни CDN мрежи.*

### 6. Настройка на базата данни

Уверете се, че сте създали празна база данни с име `qbox2_db` във вашия pgAdmin или чрез psql конзолата:

```sql
CREATE DATABASE qbox2_db;
```

Генерирайте и приложете структурата на базата данни:

```bash
python manage.py makemigrations
python manage.py migrate
```

### 7. Създаване на Суперпотребител

За да получите достъп до административния панел, създайте своя акаунт:

```bash
python manage.py createsuperuser
```

### 8. Стартиране на сървъра

```bash
python manage.py runserver
```

Проектът вече е достъпен във вашия браузър на адрес: **http://127.0.0.1:8000/**
